## 💎 Features at a Glance

- **Multi-Format Extraction:** Download music in true Lossless **FLAC**, **OPUS** (high efficiency), **MP3** (320kbps), or **M4A**.
- **Smart Deduplication:** Intelligently cleans artist names, removes duplicate tracks, and prevents redundant downloads.
- **Synchronized Karaoke Lyrics:** Real-time scrolling lyrics powered by the LRCLIB API with automatic timing alignment.
- **Hi-Fi Playback Engine:** Studio-grade playback powered by `just_audio` with seamless background playback and lock-screen controls.
- **Glassmorphic Material 3 Design:** Built around the **Prism Soundwave** aesthetic featuring dynamic color shifting, neon waveforms, and frosted acrylic card overlays.
- **Open Storage:** Saves music directly to your public `/Music/SpectraFlow/` directory and triggers automatic Android media indexer refresh.
- **Privacy First & Zero Ads:** 100% Free and Open Source. No trackers, no bloatware, no telemetry.

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (>= 3.13.0)
- Android SDK (API Level 21+)

### 📱 Direct Download (Android APK)
Pre-built installable APK files are available in [Releases](https://github.com/BeerBro6/spectraflow/releases).

### Build from Source
```bash
# Clone the repository
git clone https://github.com/BeerBro6/spectraflow.git

# Enter project directory
cd spectraflow

# Get packages
flutter pub get

# Run on connected device or emulator
flutter run
```
