# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The SpectraFlow team takes security and user privacy seriously. If you believe you have discovered a vulnerability or security issue within this project, please report it privately:

1. **Do not open a public GitHub issue** describing the vulnerability.
2. Email the maintainers directly at **beerbro920@gmail.com** or open a private security advisory through the GitHub repository's Security tab.
3. Include detailed steps to reproduce, impact analysis, and proof-of-concept material where applicable.

We will acknowledge receipt within 48 hours and work with you on remediation before any public disclosure.
